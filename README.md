## 🚀 Featured Projects

<details>
<summary><b>🔴 ARP Spoof Detector — C-Based MITM Detection Tool</b></summary>
<br>

A low-level C program that monitors live network traffic and detects ARP spoofing attacks in real time. The tool inspects ARP reply packets, correlates IP-to-MAC mappings against a trusted baseline, and alerts the user immediately upon detecting suspicious activity indicative of a Man-in-the-Middle (MITM) attack.

| Attribute | Details |
|-----------|---------|
| **Stack** | C, libpcap, POSIX sockets, ARP protocol |
| **Scale** | Local network monitoring; LAN-wide ARP table inspection |
| **Performance** | Real-time packet-level detection with minimal system overhead |
| **Security** | Passive monitoring only; no active injection; read-only network access |
| **Impact** | Demonstrates practical mastery of C, raw socket programming, and network protocol internals |
| **Repository** | [github.com/narinaresh/arp-spoof-detector](https://github.com/narinaresh/arp-spoof-detector) |

This project was built to solve a real threat: ARP poisoning is a foundational MITM attack vector and yet remains widely undetected on local networks. Writing the detector in C gave direct access to raw packet structures, reinforcing deep understanding of the ARP protocol at the byte level — knowledge that directly translates into exploitation research.

</details>

The tool cycles identity at configurable intervals, reducing network traceability during authorized assessments.

| Attribute | Details |
|-----------|---------|
| **Stack** | Python 3, subprocess, iproute2, macchanger, Linux networking stack |
| **Scale** | Single interface; configurable rotation intervals |
| **Performance** | Sub-second address rotation with no manual intervention required |
| **Security** | Designed for authorized use on owned/test networks only |
| **Impact** | Practical offensive tool demonstrating network anonymization and Linux internals knowledge |
| **Repository** | [github.com/narinaresh/ip-mac-changer](https://github.com/narinaresh/ip-mac-changer) |

Network traceability is a key concern in red team operations. This tool automates what is typically a multi-step manual process — bringing down the interface, changing MAC, reassigning IP, restoring the interface — into a single Python invocation with optional looping. It reflects a practical, automation-first engineering approach to offensive tooling.

</details>
